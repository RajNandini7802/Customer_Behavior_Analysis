#                                                                         📊 Customer Shopping Behavior Analysis

## ⭐ Overview

This project analyzes 3,900 customer transactions to uncover insights about shopping patterns, revenue drivers, category performance, and age-wise purchasing behavior. It demonstrates the full analytics workflow—from data cleaning to SQL analysis and dashboard creation in Power BI.

## 🛠 Tech Stack

Python – Pandas, NumPy (EDA & Cleaning)

MySQL – CTEs, CASE, Aggregations

Power BI – Visualization (Direct SQL Connection)

Excel – Initial review and checks

## 🔄 Project Workflow

### 1️⃣ Data Cleaning & EDA (Python)

Identified missing values

Treated nulls using median imputation

Explored distributions, patterns, and outliers

Prepared clean dataset for SQL analysis

### 2️⃣ Data Analysis (SQL)

Used SQL to generate deeper business insights:

CTEs to simplify complex queries

CASE statements to categorize age groups & ratings

Grouping, and aggregations

Revenue, sales, and subscription comparisons

### 3️⃣ Dashboard (Power BI)

Connected Power BI directly to SQL

No DAX used—logic handled entirely in SQL

Designed user-friendly visuals for:

Category-wise sales & revenue

Age-group behavior

Subscription vs non-subscription trends

Review rating distribution

## 📈 Key Insights

Clothing is the top revenue and top sales category

Seniors & Middle-aged customers spend the most

Young adults purchase frequently but spend less

70.59% shoppers are non-subscribers

Average purchase amount: ₹60.48

Average rating: 3.77
